# Vector provenance

These files are a **verbatim copy** of `docs/sync-vectors/v1/` from
`github.com/ShivaClaw/careerseeker`, vendored so this package runs standalone.

- Source repo commit: `d2c6a9ae88af3ca0ed1257a1afc6e085c5c9d10c` (`main`, 2026-09-22)
- Vectors last modified upstream: `e3346dc` (2026-09-10) — 29 declared cases: 19
  envelope, 3 pairing, 5 Play entitlement, and 2 entitlement-ack vectors.
- Per-file digests: `SHA256SUMS`
- Aggregate digest printed by every conformance run:
  `b47ad1cc86bfe61ccde184f11b4f6f206be33e65d896b6387a204607c2bfb4c6`

**The copy is a convenience, not the contract.** The upstream corpus is authoritative and
is regenerated by `docs/sync-vectors/generate.mjs`. Run against upstream directly with:

```
swift run conformance --vectors /path/to/careerseeker/docs/sync-vectors/v1
```

If the aggregate digest printed by a run differs from the one above, the corpus moved and
this copy is stale. Re-vendor rather than reconciling by hand.

> The keys and nonces in these files are published test values. They MUST NOT appear in
> any build. Fixed nonces are correct only here — reusing a nonce with a real key
> destroys AES-GCM's security entirely.
